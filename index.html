DeskBoard

A private, personal dashboard app.

DeskBoard is a personal dashboard that runs on its owner's own computer and Android phone. It shows that person's own tasks, calendar, fitness, weather and budget information on one screen.

DeskBoard is not a public product or service. It is not distributed in any app store, and it is used only by the person who built it.

Google Drive

DeskBoard asks for access to Google Drive so that it can read the small data files kept in its owner's own "DeskBoard" folder and add small files to that folder when an item is ticked off. It does not send Drive data to anyone else.

See the privacy policy for details.

DeskBoard is a personal project and is not affiliated with Google.
